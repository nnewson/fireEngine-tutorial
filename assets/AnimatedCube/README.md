# AnimatedCube

These files are the Khronos glTF Sample Models `AnimatedCube` asset:

<https://github.com/KhronosGroup/glTF-Sample-Models/tree/main/2.0/AnimatedCube>

The upstream repository identifies this model as
[CC0 1.0 public domain](https://creativecommons.org/publicdomain/zero/1.0/).
The `.gltf`, external buffer, base-color image, and metallic-roughness image are
kept together exactly as an external-file sample so builds and tests never need
to download tutorial content. Version 0.8 renders the base-color image; the
metallic-roughness image remains committed because it is part of the upstream
asset even though lighting and physically based shading are outside this
tutorial stage.
